Cómo funciona la detección

YouTube entrega las estadísticas actuales, no un historial público completo. La velocidad y aceleración reales se calculan desde las mediciones que guardes con este Radar. Cuantas más mediciones separadas por tiempo, mejor será la comparación.

Los resultados dependen de la API oficial de YouTube y de tu clave. El filtro Shorts es aproximado porque la API no ofrece un campo fiable que identifique todos los Shorts.

Configuración

Clave de YouTube Data API v3

Necesitás una clave propia de Google Cloud con YouTube Data API v3 habilitada. La clave se guarda solo en este navegador, en tu dispositivo.

Guía oficial: habilitar YouTube Data API · crear credenciales

Datos locales

El historial se guarda en el almacenamiento local del navegador. Si borrás los datos del navegador o cambiás de navegador, podrías perderlo. Exportá un CSV como respaldo.
